Try Moments

conda create -n blyx-demo --override-channels \
  -c https://rahulchaube1.github.io/blyx-packages blyx-moments

Activate the environment, then run the example in share/blyx/moments with the Blyx compiler. The installation guide includes Windows, macOS and Linux commands.
